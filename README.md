# VoxLine

VoxLine — ваш персональный центр управления TikTok LIVE.
VoxLine помогает вести эфир, не теряя связь с аудиторией. Приложение подключается к активному TikTok LIVE, показывает сообщения зрителей в реальном времени и превращает комментарии в живой голос прямо во время трансляции.

Настройте удобный голос, скорость, громкость и задержку озвучки. Выбирайте системные и локальные голоса, используйте Piper, XTTS, ElevenLabs или Cartesia. Можно включить автоматическую озвучку, читать только вопросы, добавлять стоп-фразы и управлять эфиром с помощью горячих клавиш.

VoxLine озвучивает только самые актуальные комментарии, поэтому чат не превращается в очередь и не перегружает эфир. Входы зрителей и подарки не перебивают речь, а аудиоданные локальных голосов остаются на вашем компьютере.

Это удобный инструмент для стримеров, ведущих и авторов, которые хотят сделать эфир живее, быстрее отвечать зрителям и не пропускать важные сообщения.
